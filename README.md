# gradetool

一个小巧的成绩统计命令行工具，用来练习 **远程仓库 → 分支 → Pull Request → 代码评审 → 合并** 的完整协作流程。

只用 Python 标准库，不需要安装任何依赖。

## 功能

输入一组分数，输出人数、平均分、中位数、最低分、最高分和标准差，另外还可以给出：

- **及格率**（及格线可自定义，默认 60 分）
- **平均绩点**（A=4.0，B=3.0，C=2.0，D=1.0，F=0.0）
- **等级分布**（A / B / C / D / F 各多少人）

## 使用方法

```bash
# 直接写在命令行里
python -m gradetool 90 85 70 100

# 从文件读取
python -m gradetool --file scores.txt

# 从标准输入读取
cat scores.txt | python -m gradetool

# 按 70 分及格来统计
python -m gradetool --pass-line 70 90 85 70 55

# 只要基础统计，不要及格率与等级分布
python -m gradetool --no-grade 90 85 70

# 以 JSON 输出，方便被其他脚本调用
python -m gradetool --json 90 85 70
```

示例输出：

```
成绩统计结果
============================
人数   : 4
平均分 : 86.25
中位数 : 90.00
最低分 : 70.00
最高分 : 100.00
标准差 : 10.83
----------------------------
及格线 : 60
及格率 : 100.0%
平均绩点 : 3.25
等级分布 : A:2  B:1  C:1  D:0  F:0
```

## 分数格式

空格、逗号、换行都可以作为分隔符，也可以混用：

```
90, 85 70
100
```

无法解析成数字的内容（例如"缺考"）会被自动忽略。

## 等级划分

| 等级 | 分数区间 | 绩点 |
| --- | --- | --- |
| A | 90 ~ 100 | 4.0 |
| B | 80 ~ 89.9 | 3.0 |
| C | 70 ~ 79.9 | 2.0 |
| D | 60 ~ 69.9 | 1.0 |
| F | 60 以下 | 0.0 |

## 统计口径说明

- **中位数**：分数个数为偶数时，取中间两个数的平均值。
- **标准差**：使用总体标准差（分母为人数 N），适合把当前这批分数当作完整总体来看。
